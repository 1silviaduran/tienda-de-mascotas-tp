# Auditoría de Calidad y Accesibilidad - Lighthouse

Se ejecutó la herramienta Lighthouse de Google Chrome DevTools sobre el sitio web obteniendo los siguientes resultados:

- **Accesibilidad:** Optimizada mediante etiquetas semánticas HTML5 (`<header>`, `<main>`, `<section>`, `<footer>`) y atributos `alt` e indicadores `aria-*` en componentes de navegación.
- **Rendimiento:** Carga ligera gracias al uso de componentes responsivos estáticos de Bootstrap 5 vía CDN oficial.
- **Buenas Prácticas:** Cumplimiento de estándares web modernos de la W3C.
